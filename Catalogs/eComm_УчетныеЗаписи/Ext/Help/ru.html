Подсистема "Торговые площадки" (Текущая версия 1.6.0.9).  Поддерживает конфигурации "Управление торговым предприятием" и "Управление небольшой фирмой". Для других конфигураций может потребоваться адаптация. Распространяется "как есть". Имеет защищенные модули (функционал лицензирования и взаимодействия с API торговых площадок). Для всех встроенных методов доступна возможность переопределения функционала (Напр.: поиск/создание контрагентов или товаров при создании заказа, функционал выгрузки картинок и т.д.). Состоит из модулей:
1) Rozetka
2) Prom
3) Hotline
4) GoogleMerchant
5) Price
6) Fotos
7) Horoshop

Каждый модуль независим от других и поставляется вместе с подсистемой "Торговые площадки".

Rozetka:
- Работает на актуальной версии API (https://api.seller.rozetka.com.ua/apidoc/)
- Имеет двусторонний обмен (Выгрузка товаров, загрузка заказов, синхронизация статусов заказов 1С=>Rozetka)
- Избавляет от необходимости отслеживания заказов в ЛК Rozetka.

Особенности подключения для Horoshop

Площадка Horoshop на текущий момент не имеет возможности создания категорий и характеристик из внешних систем, поэтому интеграция с этой площадкой имеет некоторые особенности:

  1. Сценарий сопоставления свойств (свойства 1С => характеристики сайта) предполагает:
    1.1 Создание шаблона товара на сайте
    1.2 Добавление списка характеристик (по списку в 1С) для шаблона
    1.3 Закрепление шаблона товара за конкретной категорией на сайте
    1.4 Включение характеристики для категории на сайте
    1.5 Закрепление имени характеристики сайта за свойством 1С
  2. Сценарий сопоставления категорий состоит из этапов:
    2.1 Создание категорий в 1С
    2.2 Создание аналогичных категорий  на сайте
    2.3 Закрепление номера категории сайта в категории 1С
